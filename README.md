# SaruMon

**ネットワークの送受信を、タスクバーの通知領域で確認できる Windows アプリです。**

監視する Wi-Fi・有線 LAN・VPN などのインタフェースを選ぶと、白地のアイコンに、受信時は緑の下向き矢印、送信時は赤の上向き矢印を表示します。ウィンドウを開くと、送受信速度・通信量・直近のグラフを確認できます。

**[最新版をダウンロード（Windows x64）](https://github.com/sarulab-ou/SaruMon/releases/latest)**

.NET ランタイム同梱。利用時に .NET を追加インストールする必要はありません。インタフェース全体の通信量と現在の TCP 接続の表示は通常権限で利用できます。相手ごとの TCP 通信量または UDP 送信先の観測を開始するときだけ、管理者権限の確認が表示されます。

## 主な機能

- 監視するネットワークインタフェースを選択し、次回起動時にも引き継ぎます。
- 通知領域の白地アイコンに、通信があった方向だけ固定色の太い矢印を表示します。通信がない方向の矢印は消え、未接続時はオレンジの × を表示します。
- 「ユニキャスト通信だけで矢印を表示」で、ブロードキャスト・マルチキャストによる点滅を除外できます。通常権限で使え、設定は次回起動時にも引き継ぎます。
- 0.5 秒ごとの速度、選択してからの通信量、直近約 60 秒のグラフを表示します。
- 選択したインタフェースの TCP 接続先 IP・ポート・状態を確認できます。
- TCP の相手 IP ごとに上り・下りの合計、接続回数、開始時刻・最終時刻を記録し、CSV 保存できます。
- 必要なときに UDP 送信先の観測を開始し、宛先ごとの開始時刻・最終時刻と累積送信バイト数を確認できます。
- TCP・UDP の宛先を任意で逆引きし、IP・ポートと併せてホスト名を表示します。
- UDP 送信の記録を「保存」から CSV に保存できます。観測を停止した後も保存できます。
- ウィンドウを閉じても監視を続けます。もう一度起動すると、既存のウィンドウが開きます。
- Windows ログイン時の自動起動と、アプリ内からの更新に対応します。

## ダウンロードとインストール

### インストーラー版

最新版のリリースページから `SaruMon-<バージョン>-Setup-x64.exe` をダウンロードし、実行して画面の案内に従います。例えば v0.1.7 のファイル名は `SaruMon-0.1.7-Setup-x64.exe` です。

現在の Windows ユーザー向けにインストールし、スタートメニューへショートカットを追加します。デスクトップへのショートカットは選択できます。標準のインストール先は `%LOCALAPPDATA%\Programs\SaruMon` です。

インストーラーの **「Windows ログイン時に起動」** は初期状態で有効です。次回ログインから通知領域で起動します。不要な場合はインストール時にチェックを外すか、インストール後にアプリ内で無効にできます。

### ZIP 版

`SaruMon-win-x64.zip` を書き込み可能なフォルダーへ展開し、`SaruMon.exe` を実行します。インストールせずに利用できます。ログイン時の自動起動が必要な場合は、アプリ内の「Windows ログイン時に起動」を有効にしてください。

## 使い方

1. スタートメニュー、または `SaruMon.exe` から起動します。
2. 「監視するインタフェース」で対象を選びます。
3. 「通知領域に格納」、最小化、またはウィンドウの × で常駐させます。

通知領域のアイコンをクリックすると、ウィンドウが開きます。

### アイコンを時計の近くに常時表示する

1. タスクバー右端の **`^`（隠れているインジケーター）** を開きます。
2. SaruMon の白地のアイコン（通信時は下りが緑、上りが赤の矢印）を、時計の近くの通知領域へドラッグします。マウスを重ねると SaruMon の名前と通信速度を確認できます。

隠れている領域から通知領域へドラッグして表示する方法は、[Microsoft のタスクバー設定の案内](https://support.microsoft.com/en-us/windows/experience/personalization/customize-the-taskbar-in-windows)にも記載されています。

Windows の設定に SaruMon の項目が複数ある場合は、いま動作中のアイコンを直接ドラッグしてください。検証用フォルダーや別の場所のコピーを起動している場合は、その SaruMon をいったん終了し、スタートメニューからインストール済みの SaruMon を起動します。標準の起動先は `%LOCALAPPDATA%\Programs\SaruMon\SaruMon.exe` です。

**ログイン時の自動起動と、アイコンの常時表示は別の設定です。** 自動起動を有効にしても、Windows がアイコンを `^` の中に置くことがあります。時計の近くに出すには、上の表示操作も行ってください。

### 通信状態と終了

| アイコンの表示 | 状態 |
| --- | --- |
| 緑の下向き矢印 | 受信中 |
| 赤の上向き矢印 | 送信中 |
| 緑と赤の矢印を同時に表示 | 送受信中。方向ごとに独立して表示 |
| その方向の矢印なし | その方向に表示対象の通信なし。両方向とも対象の通信がなければ白地だけを表示 |
| オレンジの × | 未接続、または対象を利用できない状態 |

矢印の色と濃さは固定です。0.5 秒ごとの更新で、直前の計測区間に通信があった方向の矢印を表示します。通信が続く間は表示し、通信がなくなると消えます。

自動起動の有効・無効は、アプリ内の「Windows ログイン時に起動」で変更できます。完全に終了するには、通知領域の右クリックメニュー、または **ファイル → 終了** を選びます。

### ユニキャスト通信だけで矢印を表示する

ウィンドウ下部の **「ユニキャスト通信だけで矢印を表示」** をオンにすると、選択したインタフェースでユニキャストパケットが増えた方向だけ矢印を表示します。通知領域の右クリックメニューからも切り替えられます。LAN 内の一斉送信など、ブロードキャスト・マルチキャストによる点滅を除外できます。初期状態はオフで、選択は次回起動時にも引き継ぎます。

既存の 0.5 秒ごとの統計取得を利用するため、追加の通信監視や管理者承認は不要です。**速度・通信量・グラフは、設定にかかわらずインタフェース全体の値**です。切り替えても通信量の合計はリセットしません。

ユニキャストには TCP・UDP と LAN 内の個別通信も含まれます。インターネット宛てだけを選ぶ設定ではなく、通信の正常・不正も判定しません。Wi-Fi・Ethernet を選択した場合、通常の `127.0.0.1` / `::1` の PC 内通信は対象外です。仮想アダプターでは VM などとの通信を含むことがあります。

### TCP通信の目安で矢印を表示する

ウィンドウ下部または通知領域の右クリックメニューで **「TCP通信の目安で矢印を表示」** をオンにできます。選択したインタフェースの通信量と PC 全体の TCP セグメント数が、同じ 0.5 秒の計測区間に同じ方向で増えたときに点灯します。ユニキャスト設定もオンにすると、回線側はユニキャストの増加で判定します。

PC 内部や別回線の TCP と、選択した回線の UDP が同じ計測区間に重なると、その方向の矢印が出ることがあります。初期状態はオフで、設定は次回起動にも引き継ぎます。管理者権限は不要です。

### 接続先を調べる

監視するインタフェースを選び、ウィンドウのタブを切り替えます。

| タブ | 表示するもの |
| --- | --- |
| 通信量 | インタフェース全体の受信・送信速度、合計、グラフ |
| 接続先（TCP） | 「現在の接続」の IP・ポート・状態と、「相手ごとの通信量」の上り・下り合計、接続回数、開始時刻・最終時刻 |
| UDP 送信先 | 観測を開始してからの UDP 送信先、開始時刻、累積送信バイト数、送信数、最終時刻、ローカル側 IP/ポート |

TCP 接続先は、タブを表示している間に 2 秒ごとに更新します。「再読み込み」でも更新できます。

TCP の通信量は「接続先（TCP）→ 相手ごとの通信量」で観測を開始します。同じ相手 IP との通信は、ポートや接続が異なっても上り・下りをそれぞれ合算します。接続回数は、監視中に観測した接続イベント（Connect / Accept）の回数です。監視前からの接続の回数は推測せず、イベント未観測なら 0 と表示します。ループバックで両端が監視対象の場合は、両端のイベントを加算します。

TCP・UDP の観測は初期状態では停止しています。各画面の **「開始（管理者権限）」** を押して Windows の確認を承認すると、対応する補助プロセスが観測を始めます。通常のウィンドウは一般権限のままです。別のタブや通知領域に移しても観測は続き、各画面の **「停止」** または SaruMon の終了で補助プロセスも終了します。TCP と UDP は独立して開始・停止できます。

UDP 送信の記録を最大 2,048 件保持します。時間が経っても記録を削除せず、上限に達すると新しい宛先を記録できないことを表示します。既存の宛先の集計は続きます。

開始時刻・最終時刻は、それぞれ監視中に最初・最後に観測した時刻です。TCP は接続イベントまたは送受信、UDP は送信を対象にします。実際の接続開始・終了時刻を復元するものではありません。

各一覧の **「逆引き（ホスト名を表示）」** は初期状態では無効です。有効にした場合だけ DNS に問い合わせ、取得できた名前を追加表示します。名前が取れない場合は `—` となり、IP とポートは引き続き表示します。逆引きで得た名前は閲覧サイト名とは限りません。

### 通信ログを保存する

TCP は「接続先（TCP）→ 相手ごとの通信量」で **「ログを保存…」**、UDP は「UDP 送信先」で **「保存」** を押し、CSV ファイルの保存先を選びます。クリック時点の記録を保存するので、その後に観測中の数字が変わっても保存内容は変わりません。文字コードは UTF-8（BOM 付き）です。

TCP の CSV は **相手 IP・相手名・上り合計（バイト）・下り合計（バイト）・接続回数・開始時刻・最終時刻** の 7 列です。ポートや個別の接続行は保存しません。相手名は逆引きが有効で取得済みの場合だけ保存し、それ以外は空欄になります。

UDP の CSV は 12 列で、インタフェース、プロトコル（UDP）、ローカル側と宛先の IP・ポート、逆引きホスト名、開始時刻、最終時刻、総送信量（バイト）、送信イベント数、記録範囲を含めます。UDP は接続回数を持たず、送信イベント数を記録します。逆引きホスト名は、逆引きが有効で取得済みの場合だけ保存します。

停止後も記録を保存できます。**新しく観測を開始するか、インタフェースを変更すると、それまでの記録を消去します。** アプリを終了する前に、必要な記録を保存してください。通信量は観測開始後に取得できたイベントの合計です。TCP は送信と受信、UDP は送信だけを集計します。

## 更新・アンインストール

**ヘルプ → 更新を確認** から、公開済みの正式版を確認できます。新しい版があれば、確認後にダウンロードし、SHA-256 を照合して置き換え・再起動します。更新にはインターネット接続と、アプリのフォルダーへの書き込み権限が必要です。

インストーラー版は Windows の **設定 → アプリ → インストールされているアプリ → SaruMon** から削除できます。ZIP 版は SaruMon を終了して展開先を削除します。自動起動を有効にしている ZIP 版は、先にアプリ内で無効にしてください。

選択したインタフェースなどの設定は `%LOCALAPPDATA%\SaruMon` に保存します。アンインストール後も設定を残すため、再インストール時に引き継げます。

## 監視範囲と制限

- Windows が提供する通信統計と接続情報を読み取ります。パケットの内容や Web の閲覧 URL は取得せず、アプリ別の通信内訳も表示しません。
- 表示する速度はサンプル間の平均です。通信量は現在の監視中の集計で、履歴は自動保存しません。CSV は各監視画面の保存ボタンから保存します。
- TCP・UDP とも、選択したインタフェースのローカル IP に対応する IPv4 / IPv6 を対象にします。
- 「現在の接続」は OS が提供する TCP 接続一覧です。「相手ごとの通信量」は観測開始後の送受信量で、過去の通信量は復元しません。「UDP 送信先」の集計と CSV は UDP 送信だけを対象にします。
- TCP は最大 2,048 相手、UDP は最大 2,048 フローを保持します。上限やイベント欠落で一部を記録できなかった場合は画面に表示します。TCP は保存ダイアログと保存ファイル名にも「一部未記録」と表示し、UDP は CSV の記録範囲にも含めます。
- インタフェースの接続状態は、インターネットへの到達性を保証するものではありません。
- 対応する配布形式は Windows x64 です。ZIP 版の実行ファイルを移動した場合は、自動起動を設定し直してください。
