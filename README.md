# SaruMon

**ネットワークの送受信を、タスクバーの通知領域で確認できる Windows アプリです。**

監視する Wi-Fi・有線 LAN・VPN などのインタフェースを選ぶと、受信は緑の下向き矢印、送信は赤の上向き矢印が光ります。ウィンドウを開くと、送受信速度・通信量・直近のグラフを確認できます。

**[最新版をダウンロード（Windows x64）](https://github.com/sarulab-ou/SaruMon/releases/latest)**

.NET ランタイム同梱。利用時に .NET を追加インストールする必要はありません。通信量と TCP 接続先の表示は通常権限で利用でき、UDP 送信先の観測を開始するときだけ管理者権限の確認が表示されます。

## 主な機能

- 監視するネットワークインタフェースを選択し、次回起動時にも引き継ぎます。
- 通知領域の上下矢印が、直近の送受信速度に応じて独立に発光します。通信がない方向は暗い灰色、未接続時はオレンジの × で表示します。
- 0.5 秒ごとの速度、選択してからの通信量、直近約 60 秒のグラフを表示します。
- 選択したインタフェースの TCP 接続先 IP・ポート・状態を確認できます。
- 必要なときに UDP 送信先の観測を開始し、宛先ごとの初回検出時刻と累積送信バイト数を確認できます。
- TCP・UDP の宛先を任意で逆引きし、IP・ポートと併せてホスト名を表示します。
- UDP 送信の記録を「ログを保存」から CSV に保存できます。観測を停止した後も保存できます。
- ウィンドウを閉じても監視を続けます。もう一度起動すると、既存のウィンドウが開きます。
- Windows ログイン時の自動起動と、アプリ内からの更新に対応します。

## ダウンロードとインストール

### インストーラー版

最新版のリリースページから `SaruMon-<バージョン>-Setup-x64.exe` をダウンロードし、実行して画面の案内に従います。例えば v0.1.3 のファイル名は `SaruMon-0.1.3-Setup-x64.exe` です。

現在の Windows ユーザー向けにインストールし、スタートメニューへショートカットを追加します。デスクトップへのショートカットは選択できます。標準のインストール先は `%LOCALAPPDATA%\Programs\SaruMon` です。

インストーラーの **「Windows ログイン時に起動」** は初期状態で有効です。次回ログインから通知領域で起動します。不要な場合はインストール時にチェックを外すか、インストール後にアプリ内で無効にできます。

### ZIP 版

`SaruMon-win-x64.zip` を書き込み可能なフォルダーへ展開し、`SaruMon.exe` を実行します。インストールせずに利用できます。ログイン時の自動起動が必要な場合は、アプリ内の「Windows ログイン時に起動」を有効にしてください。

## 使い方

1. スタートメニュー、または `SaruMon.exe` から起動します。
2. 「監視するインタフェース」で対象を選びます。
3. 「通知領域に格納」、最小化、またはウィンドウの × で常駐させます。

通知領域のアイコンをクリックすると、ウィンドウが開きます。

### アイコンを時計の近くに常時表示する

1. タスクバー右端の **`^`（隠れているインジケーター）** を開きます。
2. SaruMon の上下矢印のアイコン（下りは緑、上りは赤）を、時計の近くの通知領域へドラッグします。マウスを重ねると SaruMon の名前と通信速度を確認できます。

隠れている領域から通知領域へドラッグして表示する方法は、[Microsoft のタスクバー設定の案内](https://support.microsoft.com/en-us/windows/experience/personalization/customize-the-taskbar-in-windows)にも記載されています。

Windows の設定に SaruMon の項目が複数ある場合は、いま動作中のアイコンを直接ドラッグしてください。検証用フォルダーや別の場所のコピーを起動している場合は、その SaruMon をいったん終了し、スタートメニューからインストール済みの SaruMon を起動します。標準の起動先は `%LOCALAPPDATA%\Programs\SaruMon\SaruMon.exe` です。

**ログイン時の自動起動と、アイコンの常時表示は別の設定です。** 自動起動を有効にしても、Windows がアイコンを `^` の中に置くことがあります。時計の近くに出すには、上の表示操作も行ってください。

### 通信状態と終了

| アイコンの表示 | 状態 |
| --- | --- |
| 緑の下向き矢印 | 受信中 |
| 赤の上向き矢印 | 送信中 |
| 緑と赤の矢印が同時に発光 | 送受信中。方向ごとに独立して表示 |
| 暗い灰色の矢印 | その方向の通信なし |
| オレンジの × | 未接続、または対象を利用できない状態 |

直近の通信速度が大きいほど、各矢印の発光が段階的に強くなります。発光の強さは累積の通信量ではなく、0.5 秒ごとに計測する受信・送信速度をそれぞれ反映します。

自動起動の有効・無効は、アプリ内の「Windows ログイン時に起動」で変更できます。完全に終了するには、通知領域の右クリックメニュー、または **ファイル → 終了** を選びます。

### 接続先を調べる

監視するインタフェースを選び、ウィンドウのタブを切り替えます。

| タブ | 表示するもの |
| --- | --- |
| 通信量 | インタフェース全体の受信・送信速度、合計、グラフ |
| 接続先（TCP） | 現在の TCP 接続の宛先 IP・ポート・状態・ローカル側 IP/ポート |
| UDP 送信先 | 観測を開始してからの UDP 送信先、初回検出時刻、累積送信バイト数、送信数、最終検出時刻、ローカル側 IP/ポート |

TCP 接続先は、タブを表示している間に 2 秒ごとに更新します。「再読み込み」でも更新できます。

UDP の観測は初期状態では停止しています。**「開始（管理者権限）」** を押して Windows の確認を承認すると、補助プロセスが UDP 送信を観測します。通常のウィンドウは一般権限のままです。別のタブや通知領域に移しても観測は続き、**「停止」** または SaruMon の終了で補助プロセスも終了します。

UDP 送信の記録を最大 2,048 件保持します。時間が経っても記録を削除せず、上限に達すると新しい宛先を記録できないことを表示します。既存の宛先の集計は続きます。初回検出時刻は、この観測でその宛先への送信を初めて見つけた時刻です。通信が実際に開始した時刻とは限りません。

各一覧の **「逆引き（ホスト名を表示）」** は初期状態では無効です。有効にした場合だけ DNS に問い合わせ、取得できた名前を追加表示します。名前が取れない場合は `—` となり、IP とポートは引き続き表示します。逆引きで得た名前は閲覧サイト名とは限りません。

### 通信ログを保存する

「UDP 送信先」タブで **「ログを保存…」** を押し、CSV ファイルの保存先を選びます。クリック時点の記録を保存するので、その後に観測中の数字が変わっても保存内容は変わりません。

CSV は 12 列で、インタフェース、プロトコル（UDP）、ローカル側と宛先の IP・ポート、逆引きホスト名、初回検出時刻、最終送信時刻、総送信量（バイト）、送信イベント数、記録範囲を含めます。逆引きホスト名は、逆引きが有効で取得済みの場合だけ保存します。文字コードは UTF-8（BOM 付き）です。

停止後も記録を保存できます。**新しく観測を開始するか、インタフェースを変更すると、それまでの記録を消去します。** アプリを終了する前に、必要な記録を保存してください。累積送信バイト数は観測中の UDP 送信の合計で、受信や観測開始前の通信は含みません。

## 更新・アンインストール

**ヘルプ → 更新を確認** から、公開済みの正式版を確認できます。新しい版があれば、確認後にダウンロードし、SHA-256 を照合して置き換え・再起動します。更新にはインターネット接続と、アプリのフォルダーへの書き込み権限が必要です。

インストーラー版は Windows の **設定 → アプリ → インストールされているアプリ → SaruMon** から削除できます。ZIP 版は SaruMon を終了して展開先を削除します。自動起動を有効にしている ZIP 版は、先にアプリ内で無効にしてください。

選択したインタフェースなどの設定は `%LOCALAPPDATA%\SaruMon` に保存します。アンインストール後も設定を残すため、再インストール時に引き継げます。

## 監視範囲と制限

- Windows が提供する通信統計と接続情報を読み取ります。パケットの内容や Web の閲覧 URL は取得せず、アプリ別の通信内訳も表示しません。
- 表示する速度はサンプル間の平均です。通信量は現在の監視中の集計で、履歴は自動保存しません。CSV の保存は「ログを保存」から行います。
- TCP・UDP とも、選択したインタフェースのローカル IP に対応する IPv4 / IPv6 を対象にします。
- 「接続先（TCP）」は現在の接続一覧で、接続ごとのバイト数は表示しません。「UDP 送信先」の集計と CSV は UDP 送信だけを対象にします。
- UDP 送信量は観測できたイベントを集計します。保持上限やイベントの欠落があれば表示し、CSV にも記録範囲を含めます。
- インタフェースの接続状態は、インターネットへの到達性を保証するものではありません。
- 対応する配布形式は Windows x64 です。ZIP 版の実行ファイルを移動した場合は、自動起動を設定し直してください。
