# SaruMon

**ネットワークの送受信を、タスクバーの通知領域で確認できる Windows アプリです。**

監視する Wi-Fi・有線 LAN・VPN などのインタフェースを選ぶと、白地のアイコンに、左は緑の受信バー、右は赤の送信バーを表示します。ウィンドウを開くと、送受信速度・通信量・直近のグラフを確認できます。

**[最新版をダウンロード（Windows x64）](https://github.com/sarulab-ou/SaruMon/releases/latest)**

.NET ランタイム同梱。追加の .NET インストールは不要です。インタフェース全体の通信量は通常権限で確認できます。管理者権限は「調査」の記録開始や、管理者モードでのTCP観測に使います。

## 主な機能

- 監視するネットワークインタフェースを選択し、次回起動時にも引き継ぎます。
- 通知領域の棒グラフで、1 秒ごとの受信量と送信量を表示します。未接続時はオレンジの × を表示します。
- 正方形の CPU アイコンに、PC 全体の CPU 使用率を左から右へ伸びる水色のバーで表示します。マウスを重ねるとパーセントが分かります。
- 「ユニキャスト通信だけで棒を表示」で、ブロードキャスト・マルチキャストだけの通信を表示対象から外せます。通常権限で使え、設定は次回起動時にも引き継ぎます。
- 通知領域の「通知領域をTCP通信だけにする（管理者権限）」で、アイコンの棒と速度を選択回線のTCPに絞れます。
- 「通信量」では、通常権限で選択回線全体の送受信速度・合計・直近5分のグラフと、現在のTCP接続・UDPのローカルポートを確認できます。
- 「調査」で通信をアプリ別・宛先IP別に追い、Markdownの調査レポートや全件の集計CSVを保存できます。
- 「タスク」で実行中のプロセスとCPU使用率、メモリ、親プロセスを確認できます。
- ウィンドウを閉じても監視を続けます。もう一度起動すると、既存のウィンドウが開きます。
- Windows ログイン時の自動起動と、アプリ内からの更新に対応します。

## ダウンロードとインストール

### インストーラー版

最新版のリリースページから `SaruMon-<バージョン>-Setup-x64.exe` をダウンロードし、実行して画面の案内に従います。例えば v0.1.24 のファイル名は `SaruMon-0.1.24-Setup-x64.exe` です。

現在の Windows ユーザー向けにインストールし、スタートメニューへショートカットを追加します。デスクトップへのショートカットは選択できます。標準のインストール先は `%LOCALAPPDATA%\Programs\SaruMon` です。

インストーラーの **「Windows ログイン時に起動」** は初期状態で有効です。次回ログインから通知領域で起動します。不要な場合はインストール時にチェックを外すか、インストール後にアプリ内で無効にできます。

### ZIP 版

`SaruMon-win-x64.zip` を書き込み可能なフォルダーへ展開し、`SaruMon.exe` を実行します。インストールせずに利用できます。ログイン時の自動起動が必要な場合は、アプリ内の「Windows ログイン時に起動」を有効にしてください。

## 使い方

1. スタートメニュー、または `SaruMon.exe` から起動します。
2. 「監視するインタフェース」で対象を選びます。
3. 「通知領域に格納」、最小化、またはウィンドウの × で常駐させます。

通知領域のアイコンをクリックすると、ウィンドウが開きます。

### アイコンを時計の近くに常時表示する

1. タスクバー右端の **`^`（隠れているインジケーター）** を開きます。
2. SaruMon の通信量アイコンと CPU アイコンを、時計の近くの通知領域へドラッグします。マウスを重ねると通信速度や CPU 使用率を確認できます。

隠れている領域から通知領域へドラッグして表示する方法は、[Microsoft のタスクバー設定の案内](https://support.microsoft.com/en-us/windows/experience/personalization/customize-the-taskbar-in-windows)にも記載されています。

Windows の設定に SaruMon の項目が複数ある場合は、いま動作中のアイコンを直接ドラッグしてください。検証用フォルダーや別の場所のコピーを起動している場合は、その SaruMon をいったん終了し、スタートメニューからインストール済みの SaruMon を起動します。標準の起動先は `%LOCALAPPDATA%\Programs\SaruMon\SaruMon.exe` です。

**ログイン時の自動起動と、アイコンの常時表示は別の設定です。** 自動起動を有効にしても、Windows がアイコンを `^` の中に置くことがあります。時計の近くに出すには、上の表示操作も行ってください。

### 通信状態と終了

| アイコンの表示 | 状態 |
| --- | --- |
| 左の緑の棒が上から下へ伸びる | 受信中 |
| 右の赤の棒が下から上へ伸びる | 送信中 |
| 緑と赤の棒を同時に表示 | 送受信中。方向ごとに独立して表示 |
| その方向の棒なし | その方向に表示対象の通信なし。両方向とも対象の通信がなければ白地だけを表示 |
| オレンジの × | 未接続、または対象を利用できない状態 |

1 秒ごとの通信量を、実際のアイコン上で 1 ピクセル刻みの高さにします。小さな通信も見える対数目盛りで、約 8.2 kbps 以下の通信は 1 ピクセル、約 134.2 Mbps 以上は最大の高さです。

通信速度はビット毎秒（bps、kbps、Mbps など）で表示します。1 kbps は 1,000 bps です。累積通信量と CSV の通信量はバイト単位です。

自動起動の有効・無効は、アプリ内の「Windows ログイン時に起動」で変更できます。完全に終了するには、通知領域の右クリックメニュー、または **ファイル → 終了** を選びます。

### ユニキャスト通信だけで棒を表示する

ウィンドウ下部の **「ユニキャスト通信だけで棒を表示」** をオンにすると、選択したインタフェースでユニキャストパケットが増えた方向だけ棒を表示します。通知領域の右クリックメニューからも切り替えられます。初期状態はオフで、選択は次回起動時にも引き継ぎます。

1 秒ごとの統計取得を利用するため、追加の通信監視や管理者承認は不要です。棒の高さと速度・合計・グラフには、インタフェース全体の値を使います。

ユニキャストには TCP・UDP と LAN 内の個別通信も含まれます。インターネット宛てだけを選ぶ設定ではなく、通信の正常・不正も判定しません。Wi-Fi・Ethernet を選択した場合、通常の `127.0.0.1` / `::1` の PC 内通信は対象外です。仮想アダプターでは VM などとの通信を含むことがあります。

### TCP通信の目安で棒を表示する

ウィンドウ下部または通知領域の右クリックメニューで **「TCP通信の目安で棒を表示」** をオンにできます。選択したインタフェースと PC 全体の TCP で、同じ 1 秒の計測区間に同じ方向の通信が増えたときに、その方向の全通信量を棒の高さで表示します。ユニキャスト設定もオンにすると、回線側はユニキャストの増加で判定します。

PC 内部や別回線の TCP と、選択した回線の UDP が同じ計測区間に重なると、その方向の棒が出ることがあります。初期状態はオフで、設定は次回起動にも引き継ぎます。管理者権限は不要です。

### 通知領域をTCP通信だけにする（管理者権限）

通知領域の右クリックメニューで **「通知領域をTCP通信だけにする（管理者権限）」** をオンにし、Windows の管理者承認を行います。通知領域の棒とマウスを重ねたときの速度がTCP観測値に切り替わります。起動時はオフです。TCPの集計は約1秒ごとに更新され、同じPC内で完結する通信は集計対象から外します。

この設定をオフにするとTCP観測を停止します。選択インタフェースを変えると新しい対象の集計に切り替わります。

観測には選択インタフェースのローカル IP を使います。VPN や仮想アダプターで実際にフレームが通った物理ポートを判定する機能ではありません。ETW のイベントに欠落がある場合は「一部未計測」と表示します。

## 通信量を見る

「通信量」の上段は選択回線全体の送受信速度・合計・直近5分のグラフです。下段は通常権限で取得します。「アプリ別」の右側では、選んだプロセスのTCP接続を宛先IPごとに1行にまとめ、ポート・合計件数・状態別の件数を表示します。UDPはローカルIPごとにポートと件数を表示します。UDP の「全 IPv4」「全 IPv6」は、該当するアドレス種別の全インタフェースで利用できるポートです。アプリ名を取得できない場合はPIDを表示します。

「宛先別」では、左で相手IPを選ぶと右にプロセスごとの接続件数と内訳を表示します。状態別の件数は更新時点のTCP接続表を集計した値です。アプリ別・宛先別の通信量や実際のUDPの送信先を確認するには「調査」で記録を開始します。

「DNSで逆引き」をオンにすると、「アプリ別」「宛先別」の表示中のTCP宛先をDNSに問い合わせ、取得できたホスト名をIPの下に表示します。初期設定はオフで、選択は次回起動時にも引き継ぎます。

「リセット」を押すと、選んでいる回線の通信量の合計とグラフを初期化します。

## 通信を調査する

1. 回線を選び、「調査 → 記録開始（管理者）」を押します。記録中は1秒ごとに画面が更新されます。
2. 「宛先別」はアプリ・TCP/UDP・ポートをまたいで同じ宛先IPを1行にまとめます。「アプリ別」でアプリを選ぶと、そのアプリの宛先を確認できます。宛先をダブルクリックするか Enter を押すと通信の内訳が開きます。
3. 停止後も集計が残ります。「調査レポート」で全体または選択アプリを最大64 KiBのMarkdownにまとめ、プレビューから保存できます。公開・ローカルIPや実行ファイルのパスは実値です。選択アプリのレポートには、保存時点でパスが一致する `Run` / `RunOnce` の登録も載ります。「全件CSV」では保持したすべての集計行を保存できます。

上りは TCP と UDP の合計、下りは TCP の観測量です。集計はプロセス・宛先IP・ポート・プロトコルごとに最大2,048行を保持します。欠落や上限は「部分記録」、実行ファイルを確認できなかった通信は「発生元未確認」と表示します。回線またはローカルIPが変わると調査を停止し、直前の集計を保持します。

「リセット」は調査の集計とグラフを消去します。記録中はリセット後の通信から集計を続けます。

## タスクを確認・終了する

「タスク」は選択回線に関係なく、Windows が列挙した実行中のプロセスを表示します。CPU使用率、メモリのワーキングセット、親プロセスとPID、スレッド数、開始時刻を確認できます。列の見出しで並べ替え、行を選ぶと下に実行ファイルのパスが表示されます。表示中は約1秒ごとに更新し、取得できない項目は「—」で表示します。

「リセット」を押すとCPU使用率の測定をやり直します。新しい測定値が出るまで、CPU欄には「—」を表示します。

「通信量」「調査」「タスク」の一覧で行を右クリックすると、「タスクを終了」と「強制終了」が表示されます。複数のプロセスを含む行では、メニューからPIDを選びます。「タスクを終了」はアプリのウィンドウに終了を要求します。「強制終了」は確認後、選んだプロセス1件を停止します。終了にはWindows上で対象を操作する権限が必要です。

## 更新・アンインストール

**ヘルプ → 更新を確認** から、公開済みの正式版を確認できます。新しい版があれば、確認後にダウンロードし、SHA-256 を照合して置き換え・再起動します。更新にはインターネット接続と、アプリのフォルダーへの書き込み権限が必要です。

インストーラー版は Windows の **設定 → アプリ → インストールされているアプリ → SaruMon** から削除できます。ZIP 版は SaruMon を終了して展開先を削除します。自動起動を有効にしている ZIP 版は、先にアプリ内で無効にしてください。

選択したインタフェースなどの設定は `%LOCALAPPDATA%\SaruMon` に保存します。アンインストール後も設定を残すため、再インストール時に引き継げます。

## 監視範囲と制限

- Windows が提供する通信統計と接続情報を読み取ります。「調査」で明示的に開始した場合は、通信と発生元のプロセス情報を集計します。パケットの内容や Web の閲覧 URL は取得しません。
- 表示する速度はサンプル間の平均です。調査履歴のCSVは「調査」の「全件CSV」から保存します。
- TCP・UDP とも、選択したインタフェースのローカル IP に対応する IPv4 / IPv6 を対象にします。
- インタフェースの接続状態は、インターネットへの到達性を保証するものではありません。
- 対応する配布形式は Windows x64 です。ZIP 版の実行ファイルを移動した場合は、自動起動を設定し直してください。
