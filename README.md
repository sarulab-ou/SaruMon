# SaruMon

**ネットワークの送受信を、タスクバーの通知領域で確認できる Windows アプリです。**

監視する Wi-Fi・有線 LAN・VPN などのインタフェースを選び、通信中はアイコンの色でお知らせします。ウィンドウを開くと、送受信速度・通信量・直近のグラフを確認できます。

**[最新版をダウンロード（Windows x64）](https://github.com/sarulab-ou/SaruMon/releases/latest)**

.NET ランタイム同梱。利用時の追加インストールや管理者権限は不要です。

## 主な機能

- 監視するネットワークインタフェースを選択し、次回起動時にも引き継ぎます。
- 受信・送信・送受信・待機・未接続を通知領域のアイコンで表示します。
- 0.5 秒ごとの速度、選択してからの通信量、直近約 60 秒のグラフを表示します。
- ウィンドウを閉じても監視を続けます。もう一度起動すると、既存のウィンドウが開きます。
- Windows ログイン時の自動起動と、アプリ内からの更新に対応します。

## ダウンロードとインストール

### インストーラー版

最新版のリリースページから `SaruMon-<バージョン>-Setup-x64.exe` をダウンロードし、実行して画面の案内に従います。例えば v0.1.1 のファイル名は `SaruMon-0.1.1-Setup-x64.exe` です。

現在の Windows ユーザー向けにインストールし、スタートメニューへショートカットを追加します。デスクトップへのショートカットは選択できます。標準のインストール先は `%LOCALAPPDATA%\Programs\SaruMon` です。

### ZIP 版

`SaruMon-win-x64.zip` を書き込み可能なフォルダーへ展開し、`SaruMon.exe` を実行します。インストールせずに利用できます。

## 使い方

1. スタートメニュー、または `SaruMon.exe` から起動します。
2. 「監視するインタフェース」で対象を選びます。
3. 「通知領域に格納」、最小化、またはウィンドウの × で常駐させます。

通知領域のアイコンをクリックすると、ウィンドウが開きます。アイコンが見えない場合は、タスクバー右端の隠れているアイコンを確認してください。

| アイコンの色 | 状態 |
| --- | --- |
| 緑 | 受信中 |
| 青 | 送信中 |
| 紫 | 送受信中 |
| 灰 | 接続中・通信なし |
| オレンジ | 未接続、または対象を利用できない状態 |

「Windows ログイン時に起動」を有効にすると、次回ログインから通知領域で起動します。初期状態では無効です。完全に終了するには、通知領域の右クリックメニュー、または **ファイル → 終了** を選びます。

## 更新・アンインストール

**ヘルプ → 更新を確認** から、公開済みの正式版を確認できます。新しい版があれば、確認後にダウンロードし、SHA-256 を照合して置き換え・再起動します。更新にはインターネット接続と、アプリのフォルダーへの書き込み権限が必要です。

インストーラー版は Windows の **設定 → アプリ → インストールされているアプリ → SaruMon** から削除できます。ZIP 版は SaruMon を終了して展開先を削除します。自動起動を有効にしている ZIP 版は、先にアプリ内で無効にしてください。

選択したインタフェースなどの設定は `%LOCALAPPDATA%\SaruMon` に保存します。アンインストール後も設定を残すため、再インストール時に引き継げます。

## 監視範囲と制限

- Windows が提供するインタフェース単位の送受信バイト数を読み取ります。パケットの内容・接続先・プロセス別通信は収集しません。
- 表示する速度はサンプル間の平均です。通信量は現在の監視中の集計で、長期の通信履歴は保存しません。
- インタフェースの接続状態は、インターネットへの到達性を保証するものではありません。
- 対応する配布形式は Windows x64 です。ZIP 版の実行ファイルを移動した場合は、自動起動を設定し直してください。
